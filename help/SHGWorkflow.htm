SHG Workflow

This workflow is intended for spectroheliograph imaging with the SHG Scanner. It is separate from the normal HelioMaker sequence workflow and uses SharpCap Pro capture together with controlled mount motion across the spectroheliograph slit.

Basic Preparation

  • Assemble the spectroheliograph, camera, mount, and solar safety equipment.
  • Connect SharpCap Pro to the imaging camera and confirm that the live view, exposure, gain, and binning are appropriate.
  • Connect the mount through PHD2 or the configured mount interface so HelioMaker can read mount capabilities and command scan motion.
  • Confirm that observer location, time, and focal length settings are correct.
  • Enable Enable SHG scanning in Advanced Settings if the SHG tool is disabled.

Prepare Tracking and Framing

  1. Open Dynamic Target Tracking and select the Sun.
  2. Center the solar disk and orient the spectroheliograph slit for the scan axis you plan to use.
  3. Start Dynamic Target Tracking when appropriate, or otherwise make sure the mount is tracking the Sun well enough for the scan.
  4. Open the SHG Scanner from the Tools menu or from the SHG Scanner button in the DTT dialog.

Configure the Scan

  • Select the scan axis and direction. When available, choose a direction that returns the mount near the starting position after capture.
  • Set the extra scan margin so the sweep covers the full solar disk plus a small safety margin.
  • Choose an oversampling factor or, for fixed legacy MoveAxis speeds, review the resulting oversampling shown by HelioMaker.
  • Set pre/post capture time so SharpCap records a small buffer before and after the computed scan interval.
  • Use Custom FPS only when the scanner calculations should use a frame rate different from the exposure-derived nominal FPS.
  • Open SHG Preferences to configure stall detection, 8-bit capture handling, MoveAxis speed interpretation, and scanner return method.

SharpCap Capture Format

The scanner expects SharpCap to be ready for SER capture with an accepted mono or raw format. If SharpCap is not already configured this way, HelioMaker can offer to prepare the capture settings before the scan starts. The Allow 8-bit capture preference controls whether 8-bit capture formats are accepted or whether HelioMaker should prefer 16-bit output.

Run and Monitor

  1. Review scan speed, solar diameter, capture time, and any orange warning panel shown by HelioMaker.
  2. For repeated scans, configure the Multi-Pass scanning section and leave enough delay between scans for the system to settle.
  3. Click Start Scan and Capture.
  4. Monitor the mount, SharpCap capture, and SHG Scanner progress until the scan and optional return motion complete.
  5. After completion, inspect the saved SER file and confirm that the solar disk crossed the slit as expected.

Troubleshooting

  • If the scanner cannot start, check that SharpCap is connected, the Sun is selected in DTT, no HelioMaker sequence is active, and the mount supports the selected scan method.
  • If the scan length is wrong, recheck focal length, binning, scan axis, slit orientation, and the Use absolute MoveAxis speeds preference.
  • If the scan undersamples the disk, reduce the scan speed when possible, increase FPS, or choose a larger oversampling factor.
  • If mount motion stalls or return motion behaves unexpectedly, review SHG Preferences and mount capability limitations.
