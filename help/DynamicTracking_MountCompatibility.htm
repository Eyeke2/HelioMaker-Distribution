Mount Compatibility for Dynamic Tracking

Dynamic Target Tracking depends on the ability to apply custom RA and Dec tracking rates to the mount. This is different from selecting one of the mount's built-in tracking modes, such as sidereal, solar, or lunar. HelioMaker must be able to send target-specific rate updates repeatedly during the session.

Capability Check

When Dynamic Target Tracking is started, HelioMaker checks the connected mount's reported capabilities. If the mount reports that custom tracking rates are not supported, HelioMaker reports the limitation clearly and falls back to legacy mount tracking rates. For generated comet and minor-body ephemeris plans, HelioMaker can still automate the legacy PHD2 comet-tracking workflow by using the PHD2 lock-shift drift method.

Fallback Workflow

If the mount cannot use custom tracking rates for the Sun, Moon, or planets, the Dynamic Target Tracking dialog allows you to select the closest available legacy standard mount rate. The available choices are:

  • Solar for the Sun.
  • Lunar for the Moon.
  • Sidereal for planets and general fallback use.

For generated comet and minor-body ephemeris plans, HelioMaker automates the PHD2 comet tool by supplying precise ephemeris rate data directly, removing the manual guessing required when using PHD2's comet-tracking tool without HelioMaker.
