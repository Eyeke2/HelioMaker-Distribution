Why does the target drift excessively after enabling Dynamic Target Tracking?

If enabling Dynamic Target Tracking causes the target to drift excessively instead of improving stability, check the following items before assuming there is a mount or software problem.

1. Polar Alignment

Accurate polar alignment is a prerequisite for every setup and workflow. Dynamic Target Tracking does not replace polar alignment. If polar alignment is poor, drift will still occur, and gross polar-alignment errors will result in more significant drift.

2. Observer Location

Make sure the observer location stored in the mount is correct and consistent with the telescope's actual physical geographical location. Dynamic Target Tracking depends on accurate site information when computing real-time target rates.

If necessary, HelioMaker allows small manual corrections through the custom observer-location override in the Dynamic Target Tracking dialog. However, this override is intended only for minor tweaks. If the mount is not reasonably well synchronized with its real physical location, Dynamic Target Tracking may not produce accurate results.

3. Time and Time Zone

Ensure the mount and computer are using the correct time settings and time zone. This is important because Dynamic Target Tracking updates the tracking rate in real time and depends on accurate timing information.

4. Target Synchronization

Make sure the telescope is synced to the intended target, at least approximately, so that the declination derived from the mount coordinates is reasonably close to the actual target location. Large sync errors can reduce the accuracy of the converted tracking-rate values.

5. RA Rate Polarity

Some mounts require the opposite RA-rate polarity for Dynamic Target Tracking to work correctly. If the above items are correct and the target still drifts rapidly after enabling Dynamic Target Tracking, try toggling Invert RA rate for Dynamic Tracking in HelioMaker's PHD2 configuration dialog.
