Notes About PHD2 Dark Library and Image Calibration

In most HelioMaker planetary-imaging workflows, a PHD2 Dark Library is not required. This is especially true when using a shared camera such as the Virtual Planetary Camera in PHD2, where exposures are typically very short and the targets are bright. Under these conditions, thermal noise is usually a much smaller concern than it is in deep-sky imaging.

As a result, warnings issued by PHD2 about a missing dark library for a profile built around the Virtual Planetary Camera can usually be ignored for ordinary planetary, solar, or lunar use.

Important Exception: Live Stack with HelioMaker

An important exception is when HelioMaker is used as part of a Live Stack workflow. In that case, PHD2 may receive non-calibrated frames in a manner much closer to ordinary night-time guiding on stars. Under these conditions, creating a Dark Library or a Bad-pixel Map in PHD2 can be useful and may improve guiding reliability.

To build this calibration in that mode, SharpCap should be running in Live Stack, the telescope cover should be closed, and the dark library or bad-pixel map should be created directly inside PHD2.

This distinction is important: building a dark calibration frame in SharpCap is not the correct solution for PHD2 when using Live Stack with HelioMaker. If dark calibration or bad-pixel suppression is needed for guiding in this workflow, it should be built in PHD2, not in SharpCap.

For detailed instructions on creating a PHD2 dark library or bad-pixel map, please refer to the official PHD2 documentation.

Using a Separate Guiding Camera

If you are not using the Virtual Planetary Camera and instead guide with a separate physical guiding camera, creating a PHD2 Dark Library or Bad-pixel Map may also be reasonable. This is similar to ordinary PHD2 guiding workflows, where the guiding camera may benefit from its own calibration data.

Flat Frame Recommendation

It is highly recommended to build a master flat frame in SharpCap Pro and apply it in real time. Flat frame calibration helps achieve the best image quality by correcting for uneven illumination (e.g., vignetting) and removing sensor dust artifacts.

In Summary

PHD2 dark calibration is usually unnecessary for standard shared-camera planetary imaging, but it can be useful with Live Stack or a separate guiding camera.

For further details, please refer to the relevant sections in the official PHD2 and SharpCap documentation.
