Comets and Minor Bodies Workflow

This workflow is intended for comets, asteroids, and other natural solar-system minor bodies. It uses the Ephemeris Planner to create a time-windowed plan, then loads that plan into Dynamic Target Tracking so HelioMaker can update the required drift or tracking rates.

Prepare the Target Plan

  1. Open the Ephemeris Planner from the Tools menu or from the button next to Target body in DTT.
  2. Use COBS, Minor Planet Center, ESA NEO pages, or another trusted source to identify the object name or designation.
  3. Confirm observer location, start time, duration, and planning mode.
  4. Create or update the plan and review the altitude graph, including the optional Moon overlay when useful.
  5. Load the plan into DTT only when the current time is inside the plan window and the target is above the configured minimum altitude.

Center and Track the Object

  1. Return to DTT with the selected plan loaded.
  2. Use Slew To Target or manual mount controls to bring the object field into the camera view.
  3. Start Dynamic Target Tracking after confirming mount compatibility and safe operation.
  4. Verify that the DTT rates update and that the target remains where expected in the imaging field.

Imaging With Other Capture Applications

When PHD2 is using a physical guiding camera, HelioMaker does not need to be connected to SharpCap for comet, asteroid, or minor-body imaging. Once the planned object is centered and Dynamic Target Tracking is active, the user can continue with an existing imaging workflow while PHD2 guides on the surrounding star field.

HelioMaker updates the object drift rates in real time in the background, with precision based on the Ephemeris Planner cadence, such as 10 minutes, 2 minutes, or 1 minute. For example, NINA, SGP, or another imaging tool can take a series of exposures while HelioMaker keeps the PHD2 comet/minor-body drift rate updated.

Offline and Reuse Workflows

  • Use Add or update local model for this object when internet access is available and you may later need to plan at a site without internet.
  • Reuse an existing ready plan only while its time window still contains the current time and the observer location is still valid.
  • Create a fresh plan when the previous plan expired, was made for another site, or no longer covers the observing session.

Troubleshooting

  • If the plan cannot be loaded into DTT, check the plan time window, target altitude, observer location, and system clock.
  • If centering is inaccurate, recheck mount sync, observer coordinates, time zone, and the selected object designation.
  • If drift compensation is poor, use a finer planning mode, verify PHD2 guiding, and confirm that the loaded plan matches the current object and session.
  • If custom mount tracking rates are not supported, review Mount Compatibility for Dynamic Tracking for fallback behavior.
